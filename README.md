# 🔒 Security Considerations

Although this portfolio is primarily a frontend application, basic security principles are considered.

### Important Practices

* Avoid hard-coded private credentials
* Use environment variables for sensitive configuration
* Keep `.env` files outside version control
* Avoid unnecessary exposure of API credentials
* Validate user input
* Keep dependencies updated

The `.gitignore` file helps prevent sensitive or unnecessary files from being committed.

### Example `.gitignore`

```text
node_modules/
dist/
.env
.env.local
```

# 💻 Installation

## 1. Clone the Repository

```bash
git clone https://github.com/Deependrasingh-7068/Portfolio-Deependra-Singh.git
```

## 2. Navigate to the Project

```bash
cd Portfolio-Deependra-Singh
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

The application will then be available through the local development URL displayed in the terminal.
